# 판매·손익 대시보드 (v2.1)

단일 파일(`index.html`)로 동작합니다. 데이터(일보DB 2019.01~2026.09, 결산DB 2019.01~2026.09)는 비밀번호로 암호화되어 파일 안에 들어 있으며, 비밀번호를 입력해야 열립니다.
주소: https://k263-land.github.io/dashboard/

## 저장소 구성
- `index.html` : 대시보드 본체 (암호화된 데이터 포함, 약 2.3MB)
- `.nojekyll`  : GitHub Pages 처리용 빈 파일
- `icons/`     : 파비콘·앱 아이콘 (기존 그대로 유지, 이번 교체 대상 아님)
- `tools/`     : 데이터 재생성용 스크립트 (원본 DB는 저장소에 올리지 않음)

## 기존 저장소 교체 방법 (웹 업로드)
1. 저장소에서 `data/` 폴더, 기존 `tools/` 폴더, 기존 `index.html`, `README.md`를 삭제한다. (`icons/` 는 삭제하지 않는다)
2. 이 압축을 풀어 `index.html`, `.nojekyll`, `README.md`, `tools/` 를 업로드(Commit)한다.
3. 1~2분 후 주소에 접속해 비밀번호 입력창이 뜨는지, 입력 후 화면이 열리는지 확인한다.

## 데이터 갱신 (월 마감 후)
1. `tools/make_cube.py <결산DB1.xlsx>,<결산DB2.xlsx>,… cube.json` (결산, 여러 파일은 쉼표로 이어 통합. 빈 행·중복 헤더 행은 자동 제거)
2. `tools/make_cube_ilbo.py cube_i.json 40 cube_s.json [지점매칭표.xlsx]` (일보 + 지점 큐브)
3. `tools/build_pack.py tools/template.html cube.json cube_i.json cube_s.json <비밀번호> index.html`
- 두 스크립트 상단의 입력 파일 경로·파일명(일보DB 연도별 파일, 기초DB)은 PC 환경에 맞게 수정해야 한다.
- 지점매칭표(선택): 기초DB 형태가 없는 폐점 지점의 폐점 전 구분표(`미매칭` 시트: 지점코드·기초DB 형태 = 직영/IN/M/제외). 저장소에 올리지 않는다.
- 비밀번호는 3번의 인자로 지정한다. 변경하려면 같은 명령을 새 비밀번호로 다시 실행해 `index.html`을 교체한다.
- 생성된 `cube*.json`, 원본 DB, 지점매칭표는 저장소에 올리지 않는다.

## 보안 참고
- 데이터는 PBKDF2-SHA256(25만 회) → AES-256-GCM으로 암호화되어, 비밀번호 없이는 파일을 열어도 내용을 볼 수 없다.
- 단, 저장소가 공개이면 암호문 자체는 누구나 내려받을 수 있어 짧은 비밀번호는 시간을 들이면 추측될 수 있다. 민감도가 높으면 길고 복잡한 비밀번호를 쓰거나 비공개 배포를 권장한다.
- 비밀번호는 이 파일에 적지 않는다.

## 집계 기준 요약
- 금액 백만원(VAT 제외), 단가 천원(VAT 포함, ×1.1). 단가 = 금액(수량 제외 품목 금액 포함) ÷ 수량(수량 제외 품목 수량 제외)
- 직영 = B2C + B2B. 품목은 기초DB 변경코드로 통합, 수량제외 품목은 수량·재고수량만 0 처리
- 이익율 = 매출이익 ÷ 매출(결산) (매출 기준 선택과 무관)
- 일시불 이익율 = (매출이익 − 구독 수수료) ÷ (매출(결산) − 구독 수수료), 구독 수수료 = 결산DB 구독 열 (구독 수수료는 이익액과 동일하다는 전제)
- 결산DB 2019~2021은 환산매출·구독 값이 없어 매출(환산)=매출(결산), 구독은 2024년부터 표시
- 점포수: 직영 채널(B2C+B2B)의 월별 판매금액이 1천만원 이상인 지점(연 누계 아님, 특수 지점은 1백만원 이상). 구분 = 로드샵(창고형·L500 포함) / 현대 / 인샵(IN) / 모바일(M) / 특수, 직영 = 로드샵+현대+인샵, 폐점은 폐점 전 구분 적용, 채널·물류 코드 등은 제외
- 결산DB 채널: 직영구분 직영=B2C / 직영특수=B2B / 직영외·직영외특수=온라인 / 특판=특수. 거래선명이 'B2B'로 끝나면 B2B 채널·그룹(예외: LG유플러스-모바일_B2B 14597771은 B2C 유지). B2B MD는 한재호·손국현만(그 외는 기초DB B2B 담당, 없으면 손국현). 결산DB에는 2025년부터 특판 구분이 없어 결산 기준 특수 채널은 2024년까지만 나옴
- 지점코드 통합: 일보 `지점변경` + 300010~300019·300030 → 300010
